---

## 📌 1. Project Overview
**TripMitra AI** is a **Content-Based Personalized Tourism Recommendation and Intelligent Trip Planning Platform**. Built as a 50% working prototype mini-project, the system delivers functional, personalized travel recommendations exclusively for **Nagpur City** and surrounding regional tourist destinations.

The platform accepts multi-dimensional travel preferences (Budget, Trip duration, Key interests, Preferred experience style, Group type, and Distance radius) and computes weighted feature-vector match scores against a SQLite database of 20 authentic Nagpur places. Top-ranked destinations are rendered alongside explicit AI rationale cards ("Why this place?"), a spotlight #1 pick treatment, and a personalized day-wise itinerary.

---

## ✨ 2. Key Features
- **Authentic Nagpur Destination Dataset**: 23 authentic Nagpur & regional spots stored in SQLite database with multi-vector feature scores, verified geo-coordinates, and landmark photography.
- **Content-Based Recommendation Algorithm**: Multi-factor feature similarity calculation combining Interest Match (35%), Budget Compatibility (20%), Duration Fit (15%), Experience Match (10%), Group Compatibility (10%), and Destination Rating (10%).
- **Interactive Leaflet.js Route Map with Day Polylines**: Geospatial visualization powered by Leaflet & OpenStreetMap. Connects sequential stops for Day 1 (cyan), Day 2 (amber), and Day 3+ (emerald) with interactive custom pin popups and one-click location focus.
- **Live Open-Meteo Weather Intelligence & Tourist Advisory**: Real-time Nagpur weather conditions, temperature, humidity, sunset time, and smart packing/timing recommendations fetched from the Open-Meteo REST API (zero API keys needed).
- **Nearest-Neighbor TSP Route Optimization**: Sequenced daily schedule minimizing driving time across Nagpur using the Haversine distance formula, displaying estimated transit km and distance saved.
- **Printable Travel Pass**: One-click print/PDF generator formatting the trip summary, weather card, recommendations, and daily schedule into a clean travel document.
- **Progressive Multi-Step Planner**: Interactive step-by-step preference form (`01 Preferences` -> `02 Interests` -> `03 Travel Style` -> `04 Results`) with live budget and radius sliders.
- **AI Rationale Cards**: Automatic generation of human-readable match explanations ("Why this place?") without emojis for viva presentation.

## 🧮 5. Core Algorithms (Viva Defense Guide)

### A. Content-Based Recommendation Algorithm
The recommendation engine is implemented in `recommendation_engine.py`. Each destination in SQLite is represented as a feature vector:
`[nature_score, historical_score, spiritual_score, adventure_score, photography_score, food_score, family_friendly, entertainment_score]`.

$$\text{Final Score} = \left[ (\text{Interest} \times 0.35) + (\text{Budget} \times 0.20) + (\text{Duration} \times 0.15) + (\text{Experience} \times 0.10) + (\text{Group} \times 0.10) + (\text{Rating} \times 0.10) \right] \times \text{Distance Multiplier}$$

1. **Interest Match (35%)**: Averages vector scores across user's selected interest domains.
2. **Budget Match (20%)**: Full match (1.0) if destination cost $\le$ user budget cap; degrades smoothly if over budget.
3. **Duration Match (15%)**: Assesses fit of `ideal_duration_hours` within daily time allocation.
4. **Experience Match (10%)**: Categorical alignment with user's preferred vibe (Relaxing, Exploring, Adventure, Cultural).
5. **Group Compatibility (10%)**: Checks if group type (Solo, Friends, Family, Couple) matches place accessibility.
6. **Rating Score (10%)**: Normalized star rating ($\text{rating} / 5.0$).
7. **Distance Multiplier**: $0.65\times$ penalty if user requests within-city but destination $> 18$ km away.

### B. Nearest-Neighbor TSP Route Optimization
Implemented in `itinerary_generator.py`. Instead of random sequencing, daily stops are ordered using a greedy heuristic to solve the **Traveling Salesperson Problem (TSP)**, minimizing transit distance:
1. **Haversine Formula**: Calculates the great-circle distance $d$ in kilometers between coordinates $(\phi_1, \lambda_1)$ and $(\phi_2, \lambda_2)$:
   $$a = \sin^2\left(\frac{\Delta\phi}{2}\right) + \cos(\phi_1)\cos(\phi_2)\sin^2\left(\frac{\Delta\lambda}{2}\right)$$
   $$c = 2 \cdot \text{atan2}\left(\sqrt{a}, \sqrt{1-a}\right), \quad d = R \cdot c \quad (R = 6371\text{ km})$$
2. **Greedy Traversal**: Starting from Nagpur Zero Mile / Central hotel, the engine repeatedly chooses the nearest unvisited attraction, calculates transit buffers, and logs kilometers saved compared to naive traversal.

## 🚀 6. Installation & Local Execution Guide

### Prerequisites
- Python 3.8+ installed on your system.

### Step-by-Step Instructions

1. **Navigate to the Project Directory:**
   ```bash
   cd c:\Users\DELL\OneDrive\Desktop\AI_based_Tourism_Guide
   ```

2. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Initialize & Seed SQLite Database:**
   ```bash
   python init_db.py
   ```

4. **Launch the Flask Backend Application:**
   ```bash
   python app.py
   ```

5. **Open Application in Browser:**
   Navigate to `http://127.0.0.1:5000` in Google Chrome or any modern web browser.
