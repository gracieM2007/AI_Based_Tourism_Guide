> **College Mini-Project 50% Progress Demo**

---

## 📌 1. Project Overview
**TripMitra AI** is a **Content-Based Personalized Tourism Recommendation and Intelligent Trip Planning Platform**. Built as a 50% working prototype mini-project, the system delivers functional, personalized travel recommendations exclusively for **Nagpur City** and surrounding regional tourist destinations.

The platform accepts multi-dimensional travel preferences (Budget, Trip duration, Key interests, Preferred experience style, Group type, and Distance radius) and computes weighted feature-vector match scores against a SQLite database of 20 authentic Nagpur places. Top-ranked destinations are rendered alongside explicit AI rationale cards ("Why this place?"), a spotlight #1 pick treatment, and a personalized day-wise itinerary.

## ✨ 2. Key Features
- **Authentic Nagpur Destination Dataset**: 20 authentic Nagpur & regional spots stored in SQLite database with multi-vector feature scores and realistic landmark photography.
- **Content-Based Recommendation Algorithm**: Multi-factor feature similarity calculation combining Interest Match (35%), Budget Compatibility (20%), Duration Fit (15%), Experience Match (10%), Group Compatibility (10%), and Destination Rating (10%).
- **AI Rationale Cards**: Automatic generation of human-readable match explanations ("Why this place?") without emojis for viva presentation.

- **Day-Wise Itinerary Timeline**: Time-slotted schedule organizing top recommendations into morning, mid-day, afternoon, and evening activity slots.
- **Dedicated Coming Soon Roadmap Page (`/coming-soon`)**: Standalone product roadmap showcasing the 10 future platform enhancements (Explore India, Weather Intelligence, Maps, AI Assistant, Hotels, User Profiles, Adaptive Engine, Booking Integration, Multilingual, Smart Routing).

## 🧮 5. Recommendation Algorithm (Viva Explanation)

The recommendation engine is implemented in `recommendation_engine.py`. Each destination in the SQLite database is stored as a vector with feature attributes:
`[nature_score, historical_score, spiritual_score, adventure_score, photography_score, food_score, family_friendly, entertainment_score]`.

### Mathematical Scoring Formula:
$$\text{Final Score} = (\text{Interest Match} \times 0.35) + (\text{Budget Match} \times 0.20) + (\text{Duration Match} \times 0.15) + (\text{Experience Match} \times 0.10) + (\text{Group Compatibility} \times 0.10) + (\text{Rating Score} \times 0.10) \times \text{Distance Multiplier}$$

1. **Interest Match (35%)**: Calculates average vector score across the user's selected interest categories.
2. **Budget Match (20%)**: Full match (1.0) if destination estimated budget $\le$ user budget cap; decays smoothly if over budget.
3. **Duration Match (15%)**: Assesses fit of destination's `ideal_duration_hours` within total trip duration.
4. **Experience Match (10%)**: Checks alignment with user's preferred vibe (Relaxing, Exploring, Adventure, Cultural).
5. **Group Compatibility (10%)**: Verifies if user group type (Solo, Friends, Family, Couple) matches destination target group.
6. **Rating Score (10%)**: Normalized star rating ($\text{rating} / 5.0$).
7. **Distance Filter**: Applies a penalty multiplier ($0.65$) if user requests "Within City" but destination lies $> 18$ km away.

Final scores are scaled to $0 - 100\%$ and sorted descending to produce the **Top Recommendations** with a spotlight treatment for #1.

## 🚀 6. Installation & Local Execution Guide

### Prerequisites
- Python 3.8+ installed on your system.

### Step-by-Step Instructions

1. **Navigate to the Project Directory:**
   ```bash
   cd c:\Users\DELL\OneDrive\Desktop\AI_based_Tourism_Guide
   ```

2. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Initialize & Seed SQLite Database:**
   ```bash
   python init_db.py
   ```

4. **Launch the Flask Backend Application:**
   ```bash
   python app.py
   ```

5. **Open Application in Browser:**
   Navigate to `http://127.0.0.1:5000` in Google Chrome or any modern web browser.
